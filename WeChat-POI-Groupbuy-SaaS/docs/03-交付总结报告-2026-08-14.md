## 三、技术栈

- **后端**：FastAPI 0.111 + SQLAlchemy 2.0 异步 ORM + Pydantic v2 + SQLite/PostgreSQL + JWT + bcrypt + Alembic
- **小程序**：微信原生小程序（Native），`wx.login` / `wx.requestPayment` / `wx.scanCode`，Provider 抽象（mock/real）
- **Web 后台**：React 18 + Vite 5 + TypeScript + Tailwind 3（独立工程，同源或 CORS 调用后端）

## 四、本轮（收口阶段）完成的任务

> 背景：前序工程师与 QA 子代理因工具链缺陷（`TaskStop not found`）崩溃，主理人接管验证与修复。

1. **退款逻辑真 Bug 修复**（`app/services/refund.py`）
   - 问题：对已 `refunded` 订单再次退款，状态守卫先于重复退款守卫执行，返回 `3002`（状态非法）而非 `5002`（已退款）。
   - 修复：重排守卫顺序，重复退款守卫先行；未支付订单仍正确返回 `3002`。
2. **测试框架稳定性修复**（`tests/conftest.py`）
   - 问题：共享文件级 aiosqlite 引擎多连接池，异步全套测试下偶发 `IntegrityError`（seed 冲突）与退款端点偶发 `4001`（连接压力下响应错乱假象）。
   - 修复：改为每测试函数级 **内存库 `StaticPool`** 引擎，消除文件锁与跨测试污染。
3. **单服务部署打通**（`app/main.py` + 配置 + web-admin 重建）
   - 后端按需托管 `web-admin/dist`（`WEB_ADMIN_DIST` 留空自动取 `../web-admin/dist`），含 `/assets` 静态挂载与 SPA history 回退；`/api/*` 路由优先匹配，API 404 不被吞。
   - web-admin 以 `VITE_API_BASE=/api/v1` 重新构建，单服务模式下同源调用、无需 CORS。
4. **端口固化**（`app/core/config.py` + `.env.example`）
   - 新增 `SERVER_PORT`（默认 8000，可覆盖），避免与同机其他服务（如旧项目占用 8000）冲突。
5. **清理**
   - 删除遗留 debug 测试 `tests/test_pagination_total.py::test_debug_store_sql`（引用已移除的引擎，会 `AttributeError`）。
   - 移除 `tests/test_refunds.py` 中的临时诊断 print。

## 六、启动与部署指南

### 1. 后端（开发 / 分离模式）
```bash
cd backend
cp .env.example .env          # 按需改 JWT_SECRET / SERVER_PORT / Mock 开关
# 创建表 + 演示种子
python -m scripts.seed
# 启动（默认 8000；冲突时改 SERVER_PORT 或 uvicorn --port 8001）
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
# 健康检查
curl http://127.0.0.1:8000/api/health
```

### 2. Web 后台（开发 / 分离模式，CORS 连后端）
```bash
cd web-admin
npm install
npm run dev                   # http://localhost:5173，API 走 VITE_API_BASE（默认 :8000/api/v1）
```

### 3. 单服务部署（后端托管前端，推荐生产）
```bash
cd web-admin
VITE_API_BASE=/api/v1 npm run build     # 已构建于 dist/，同源调用
cd ../backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# 浏览器访问 http://localhost:8000 即管理后台，API 同在 /api/v1
```
> 单服务模式下 `WEB_ADMIN_DIST` 留空即自动取 `../web-admin/dist`；如需自定义路径在 `.env` 指定绝对路径。
