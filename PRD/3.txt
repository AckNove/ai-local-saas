# 《AI本地商家增长SaaS系统 PRD V1.0》

# PRD-03 AI Agent架构设计

**版本：V1.0**
**核心目标：利用AI替代传统本地生活销售、运营、内容策划中的大量人工工作，提高单人服务商家数量。**

---

# 1. AI系统总体设计

## 1.1 AI在本项目中的定位

本项目中的AI不是简单的聊天机器人，而是：

> **一个围绕“商家发现 → 商家分析 → 销售成交 → 商家运营 → 增长优化”的多Agent协作系统。**

---

传统模式：

```
销售人员
 ↓
寻找商家

运营人员
 ↓
分析需求

内容人员
 ↓
制作内容

运营人员
 ↓
持续优化
```

成本高。

---

AI模式：

```
AI商家雷达Agent
        ↓
AI诊断Agent
        ↓
AI销售Agent
        ↓
AI内容Agent
        ↓
AI增长分析Agent
```

一个人即可完成原本多个岗位工作。

---

# 3. Agent 1：AI商家雷达Agent

## 3.1 目标

解决：

> “我要卖给谁？”

---

## 3.2 使用场景

用户输入：

```
城市：广州

区域：天河

行业：餐饮

目标：
寻找适合视频号增长服务的商家
```

---

AI输出：

```
商家列表：

1. XX火锅

评分：86

原因：
- 客单价较高
- 有稳定客流
- 视频号运营不足

推荐策略：
强调私域增长。
```

---

# 3.3 数据来源设计

MVP阶段：

不做复杂爬虫。

采用：

## 数据输入：

### 地图数据

获取：

* 商家名称
* 地址
* 电话

---

### 公共互联网信息

分析：

* 视频号
* 抖音
* 小红书

---

### 人工补充

销售人员修正。

---

# 3.4 AI评分模型

评分：

100分。

公式：

```
商家价值评分

=

线上增长空间
+
商业价值
+
成交概率
```

---

维度：

## 增长空间（40分）

例如：

没有视频号运营：

高分。

---

## 商业价值（30分）

例如：

高客单价：

高分。

---

## 成交概率（30分）

例如：

老板年轻：

高分。

---

# 4. Agent 2：AI商家诊断Agent

## 4.1 目标

解决：

> “为什么老板愿意购买？”

---

## 4.2 输入

商家：

```
名称

行业

地址

线上资料
```

---

## 4.3 输出

《商家增长诊断报告》

结构：

---

## 第一部分：

当前状态

例如：

```
该门店拥有稳定线下客流。

但是：

视频号内容更新频率低。

消费者无法形成二次传播。
```

---

## 第二部分：

问题分析

```
问题1：

客户消费后流失。

问题2：

视频内容缺少互动。

问题3：

没有形成私域资产。
```

---

## 第三部分：

解决方案

```
建议：

1. 优化视频号POI

2. 部署种草卡

3. 建立AI内容运营体系
```

---

## 第四部分：

商业价值预测

例如：

```
预计：

每100位消费者：

可产生20-40次线上互动。
```

---

# 5. Agent 3：AI销售辅助Agent

## 5.1 目标

帮助你成交。

---

## 5.2 功能

## 销售话术生成

输入：

```
行业：
餐饮

老板类型：
传统老板
```

输出：

开场：

```
老板，我们最近帮助附近几家门店优化微信视频号曝光。

发现很多店都有一个问题：

客户吃完就走，没有留下线上资产。
```

---

## 5.3 异议处理

老板：

“我已经做抖音了。”

AI：

回复：

```
抖音解决的是平台曝光。

我们重点解决的是：
把到店客户转化为长期传播资产。
```

---

## 5.4 跟进提醒

CRM结合：

自动提醒：

```
XX老板3天未跟进。

建议发送：
案例+诊断报告。
```

---

# 6. Agent 4：AI内容运营Agent

## 6.1 目标

帮助商家持续生产内容。

---

## 6.2 视频脚本生成

输入：

```
行业：

火锅

活动：

新品套餐
```

输出：

```
标题：

广州天河这家火锅店终于出新品了

开头：

很多人不知道...

正文：

...

结尾：

点击定位到店体验。
```

---

# 6.3 评论生成

这是种草卡核心能力。

输入：

视频：

“新品上线”

输出：

多样化评论：

示例：

```
终于去打卡了，味道确实不错。

这家店环境很好，很适合朋友聚餐。

价格合理，下次还会来。
```

要求：

* 模拟真实用户
* 避免广告语
* 多样化表达

---

# 6.4 内容更新建议

AI分析：

```
最近5条视频：

互动下降。

建议：

增加真人体验内容。
```

---

# 7. Agent 5：AI种草互动Agent

## 7.1 目标

提高消费者参与率。

---

## 工作流程：

```
商家上传视频

↓

AI分析视频内容

↓

生成评论模板

↓

绑定种草卡

↓

消费者扫码

↓

展示互动引导
```

---

## 7.2 评论模板管理

支持：

模板库。

分类：

### 体验型

```
今天刚去体验，味道很不错。
```

---

### 推荐型

```
收藏很久终于来了，值得推荐。
```

---

### 情绪型

```
环境很舒服，周末约朋友很适合。
```

---

## 7.3 防重复机制

系统：

记录历史评论。

避免：

100个人出现完全一样内容。

---

# 10. Prompt设计规范

所有Agent必须遵循：

## 原则1：

明确角色。

例如：

```
你是一名本地生活商业增长顾问。
```

---

## 原则2：

明确目标。

例如：

```
目标：
帮助餐饮老板理解视频号增长价值。
```

---

## 原则3：

限定输出格式。

例如：

```
请按照：

问题

原因

方案

执行步骤

输出。
```
