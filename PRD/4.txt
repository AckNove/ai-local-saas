# 《AI本地商家增长SaaS系统 PRD V1.0》

# PRD-04 技术架构与数据库设计文档

**版本：V1.0**
**目标：指导AI开发团队完成MVP系统开发**
**开发原则：低成本、快速验证、可扩展**

---

# 1. 技术架构设计原则

本项目MVP阶段核心目标：

> 用最低开发成本，在7天内完成一个可以真实服务商家的AI SaaS系统。

因此技术架构遵循：

## 原则1：快速开发

优先：

* 成熟框架
* AI辅助开发
* 模块化设计

---

## 原则2：低成本运行

初期：

目标：

服务器成本：

≤100元/月。

---

## 原则3：未来可扩展

预留：

* 多租户
* 代理体系
* API扩展
* AI Agent扩展

---

整体架构：

```
                    用户层

        ┌────────────────────┐

                    ↓


        ┌────────────────────┐

                    ↓


                数据层

        Redis


                    ↓


                AI层


        LLM API

        Agent Framework
```

# 5. 数据库设计

---

# 5.1 用户表 sys_user

用途：

保存系统用户。

字段：

| 字段            | 类型       | 说明   |
| ------------- | -------- | ---- |
| id            | bigint   | 主键   |
| username      | varchar  | 账号   |
| password_hash | varchar  | 密码   |
| role          | varchar  | 角色   |
| merchant_id   | bigint   | 所属商家 |
| status        | int      | 状态   |
| created_at    | datetime | 创建时间 |

---

# 5.2 商家表 merchant_info

用途：

保存客户商家。

字段：

| 字段          | 说明   |
| ----------- | ---- |
| id          | 商家ID |
| name        | 商家名称 |
| industry    | 行业   |
| address     | 地址   |
| contact     | 联系人  |
| phone       | 电话   |
| package     | 套餐   |
| expire_time | 到期时间 |
| status      | 状态   |

---

# 5.3 门店表 store_info

字段：

| 字段            | 说明    |
| ------------- | ----- |
| id            | 门店ID  |
| merchant_id   | 商家ID  |
| name          | 门店名称  |
| location      | 地址    |
| video_account | 视频号   |
| poi_status    | POI状态 |

---

# 5.4 种草卡表 seed_card

核心表。

字段：

| 字段          | 说明      |
| ----------- | ------- |
| id          | ID      |
| merchant_id | 商家      |
| name        | 卡名称     |
| type        | NFC/二维码 |
| target_url  | 跳转地址    |
| qr_code     | 二维码     |
| status      | 状态      |

---

# 5.5 用户访问记录表 seed_event

记录消费者行为。

字段：

| 字段         | 说明  |
| ---------- | --- |
| id         | ID  |
| card_id    | 种草卡 |
| event_type | 行为  |
| device     | 设备  |
| created_at | 时间  |

行为：

```
scan

click

share

comment
```

---

# 5.6 视频内容表 video_content

字段：

| 字段          | 说明 |
| ----------- | -- |
| id          | ID |
| merchant_id | 商家 |
| title       | 标题 |
| url         | 链接 |
| category    | 类型 |
| created_at  | 时间 |

---

# 5.7 AI生成记录表 ai_task

记录AI调用。

字段：

| 字段         | 说明      |
| ---------- | ------- |
| id         | 任务ID    |
| agent_type | Agent类型 |
| input      | 输入      |
| output     | 输出      |
| created_at | 时间      |

# 6. API设计规范

---

# 6.1 通用规范

请求：

JSON

返回：

统一格式：

```json
{
 "code":200,
 "message":"success",
 "data":{}
}
```

---

# 6.2 用户接口

## 登录

POST

```
/api/auth/login
```

---

## 获取用户信息

GET

```
/api/user/profile
```

---

# 6.3 商家接口

创建商家：

POST

```
/api/merchant/create
```

查询：

GET

```
/api/merchant/list
```

---

# 6.4 种草卡接口

创建：

POST

```
/api/seed-card/create
```

访问：

GET

```
/api/seed-card/{id}
```

记录：

POST

```
/api/seed-card/event
```

---

# 6.5 AI接口

AI生成评论：

POST

```
/api/ai/comment
```

输入：

```json
{
"video":"视频内容",
"industry":"餐饮"
}
```

输出：

```json
{
"comments":[
"评论1",
"评论2"
]
}
```

---

AI生成方案：

POST

```
/api/ai/report
```
