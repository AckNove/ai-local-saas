## TL;DR
基于 6 份 PRD，用 **FastAPI + React + SQLite（可切 PG）+ 离线 Mock AI** 完成 MVP 全栈开发。后端 pytest 27/27、端到端 18/18 全通过；单 `uvicorn` 同源托管前端 + H5 + API；**无 AI Key 即可完整演示**。

## 一、技术栈（已落地）
- 后端：FastAPI + SQLAlchemy 2.0（异步）+ Pydantic v2 + PyJWT + bcrypt + segno + httpx
- 数据：SQLite 默认（`DATABASE_URL` 可切 PostgreSQL）；JWT 无状态会话；软删除（`status` 字段）
- 前端：React 18 + Vite 5 + TypeScript + Tailwind 3 + react-router-dom 6 + axios（手写 Shadcn 风格组件）
- 消费者端：纯 H5 静态页（`h5/`），由 FastAPI 直接 serve
- AI：`LLMProvider` 抽象 + `MockProvider` 离线兜底 + OpenAI/DeepSeek Provider（可选，httpx 异步）

## 四、本地一键运行
```bash
# 1) 后端依赖（venv 已就绪：C:\Users\25803\.workbuddy\binaries\python\envs\default）
PY="C:\Users\25803\.workbuddy\binaries\python\envs\default\Scripts\python.exe"
cd backend
$PY -m pip install fastapi uvicorn sqlalchemy aiosqlite pydantic pyjwt bcrypt python-dotenv segno httpx python-multipart

# 2) 初始化库 + 默认管理员（幂等，admin/admin123）
$PY seed_admin.py

# 3) 前端构建（产出 frontend/dist，由后端托管）
cd ../frontend
NODE="C:\Users\25803\.workbuddy\binaries\node\versions\22.22.2\node.exe"
NPM="C:\Users\25803\.workbuddy\binaries\node\versions\22.22.2\node_modules\npm\bin\npm-cli.js"
"$NODE" "$NPM" install
"$NODE" "$NPM" run build

# 4) 启动（单进程同源托管 API + 后台 + H5）
cd ../backend
$PY -m uvicorn main:app --host 0.0.0.0 --port 8000
```

- 消费者 H5：http://127.0.0.1:8000/c/{slug}
- API 文档：http://127.0.0.1:8000/docs

## 五、AI 配置
默认 `LLM_PROVIDER=mock`：**无 API Key 即可完整演示**（评论/诊断/内容返回结构化 Mock 结果，并落 `ai_task`）。配置 `LLM_API_KEY` + `LLM_PROVIDER=openai|deepseek` 可切真实模型（DeepSeek 国内可达）。

## 六、MVP 边界（PRD 已确认，非缺陷）
- NFC 仅数据建模 + 二维码主路径，写卡硬件验证延后（D2）
- AI 仅生成草稿/建议，不自动发布视频号（D3）
- `agent` 角色仅预留不实现，V2 再落地（D4）
- 收入统计 / CRM / 商家雷达 / 支付等 P1/P2 功能按计划裁剪
