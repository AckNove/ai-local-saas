# 文件一：前期启动成本清单 + 需准备事项

> 面向：非技术背景的经营者。
> 说明：下表每一项都标注了「多少钱 / 去哪办 / 对我项目有什么用」，让你清楚每一分钱花在哪、值不值。

---

## 一、总成本一览（第一年）

| 类别 | 金额 | 备注 |
|---|---|---|
| 营业执照（个体工商户） | **约 0 元** | 自己办免费，代办几十到几百 |
| 服务器（第一年） | **约 38-100 元** | 新用户轻量服务器首年价 |
| 域名（可选） | **约 50 元** | 可先用 IP，后面再买 |
| 备案（国内服务器必须） | **免费** | 只是走流程，约 1-2 周 |
| 小程序认证 | **300 元/个** | 每个商家一个，商家自己出（方案A） |
| **合计（你自掏腰包）** | **约 100-200 元** | 不含商家承担的小程序认证费 |

> 关键结论：**你自己第一年实际投入约 100-200 元**，就能启动。小程序认证费 300 元/个是商家出（算进你的 2500 开发费里，或让商家自己交）。

---

## 二、必须准备的东西 + 各自作用

### 1. 个体工商户营业执照（大前提，最优先办）

| 项 | 说明 |
|---|---|
| 成本 | 约 0 元（市场监管局线上免费办，代办几十元） |
| 去哪办 | 当地市场监管局线上平台（如"企业开办一网通"）或政务窗口 |
| 周期 | 几天到一两周拿执照 |
| **对我项目有什么用** | ① 注册小程序必须（个人不能开能收钱的小程序）② 申请微信支付商户号必须 ③ 后面备案也要用。**没它，小程序、支付、备案全都办不了。** |

### 2. 云服务器（让商家能访问你的系统）

| 项 | 说明 |
|---|---|
| 成本 | 约 38-100 元/年（腾讯云/阿里云轻量服务器，新用户 2核2G） |
| 去哪买 | 腾讯云或阿里云官网，搜「轻量应用服务器」，选 Ubuntu 22.04 |
| **对我项目有什么用** | 你的系统现在只在你电脑上，别人打不开。部署到服务器后，① 商家的小程序能连到你的后端 ② 你能给商家一个网址看数据 ③ 系统 24 小时在线、你电脑关机也能用。 |

### 3. 域名（可选，先用 IP 也行）

| 项 | 说明 |
|---|---|
| 成本 | 约 50 元/年 |
| 去哪买 | 腾讯云/阿里云/任意域名商 |
| **对我项目有什么用** | 把 `http://IP地址:8000` 变成 `http://你的域名.com`，① 更专业 ② 商家好记 ③ 小程序配置里更稳定。**前期可以不用，先用 IP 跑通。** |

### 4. 备案（国内服务器必须）

| 项 | 说明 |
|---|---|
| 成本 | 免费 |
| 去哪办 | 买服务器后，在云厂商后台提交 ICP 备案 |
| 周期 | 约 1-2 周 |
| **对我项目有什么用** | 国内服务器不备案，微信小程序、网页都会被限制访问。**没有备案，你的系统在国内无法正规商用。** 但前期可先用 IP 演示，备案后补。 |

### 5. 小程序（每个商家一个，商家出）

| 项 | 说明 |
|---|---|
| 成本 | 300 元/年 认证费（**商家自己出**，算进你 2500 开发费或让商家单独交） |
| 去哪办 | 微信公众平台注册，用**商家的执照**认证（方案A） |
| 周期 | 注册即时，认证 1-3 天 |
| **对我项目有什么用** | 这就是你卖给商家的"小程序"本体。视频号 POI 团购要挂这个小程序，顾客在这里下单。**这是你收费 2500-3000 开发费对应的交付物。** |

### 6. 微信支付商户号（暂缓，走模式B可先不办）

| 项 | 说明 |
|---|---|
| 成本 | 免费 |
| 去哪办 | 微信支付商户平台 |
| **对我项目有什么用** | 顾客在小程序里真实付钱用。**但你现在走"收服务费"模式，商家自己收款，你不需要商户号。** 等以后要"平台抽佣"再办。 |

### 7. 腾讯地图 Key（暂缓，可选）

| 项 | 说明 |
|---|---|
| 成本 | 免费额度够用 |
| 去哪办 | 腾讯位置服务官网 |
| **对我项目有什么用** | 实现"地图选点自动回填 POI"（不用手填经纬度）。**前期手填也能用，等确定要做地图选点再申请。** |

### 8. 视频号「交易组件」资质（关键，小程序挂 POI 团购必须）

| 项 | 说明 |
|---|---|
| 成本 | 免费申请 |
| 去哪办 | 微信公众平台，小程序后台申请"自定义交易组件" |
| **对我项目有什么用** | 小程序要能在视频号里卖团购，必须过这个审核。**这是视频号 POI 团购的硬门槛，但单商户小程序审核相对容易。** |

## 三、优先级排序（先办什么）

| 优先级 | 事项 | 谁做 | 什么时候 |
|---|---|---|---|
| **1** | 买服务器 | 你 | **现在就能做，不依赖执照** |
| **2** | 办个体工商户执照 | 你 | 现在就开始（几天拿到） |
| **3** | 域名 + 备案 | 你 | 服务器买好后（备案 1-2 周） |
| **4** | 注册小程序（用你执照先测一个） | 你 | 执照到手后 |
| **5** | 视频号交易组件资质 | 你 | 有商家要做团购时 |
| **6** | 微信支付商户号 | 你 | 走平台抽佣时才需要（暂缓） |

---

## 四、一句话总结

> **你自己第一年实际投入约 100-200 元（服务器+域名），最优先办两件事：① 买服务器（我帮你部署）② 办个体户执照（后面一切的地基）。其余（小程序认证费、备案）要么是商家出、要么免费走流程。**
