# 项目说明（给其他智能体 / 开发者）

> 本文档帮助任何 AI 编程助手或开发者快速理解本项目结构、技术栈、启动方式和修改约定。

## 一、项目概览

这是一个**本地商家微信生态 SaaS** 项目，包含两个独立子项目，共用一个 git 仓库：

| 子项目 | 目录 | 定位 | 端口 |
|---|---|---|---|
| **AI-Local-Growth-SaaS** | `AI-Local-Growth-SaaS/` | 商家增长服务：种草卡 + AI 内容 + 数据 | 8000 |
| **WeChat-POI-Groupbuy-SaaS** | `WeChat-POI-Groupbuy-SaaS/` | 视频号 POI 团购：小程序 + 团购套餐 + 核销 | 8001 |

**商业定位**：服务商模式（非平台抽佣）。帮商家做小程序、上团购、做种草卡，收「开发费 2500-3000 + 月维护费 500-600」。

## 二、技术栈（两项目一致）

| 层 | 技术 |
|---|---|
| 后端 | Python 3.11 + FastAPI + SQLAlchemy 2.0（异步）+ Pydantic v2 + Alembic |
| 数据库 | 开发 SQLite / 生产 PostgreSQL（Docker 内） |
| 前端 | React 18 + Vite 5 + TypeScript + Tailwind 3 |
| 小程序 | 微信原生小程序（`WeChat-POI-Groupbuy-SaaS/miniprogram/`） |
| 部署 | Docker Compose + gunicorn（单服务托管前端） |
| AI | LLM Provider 抽象 + Mock 兜底 + DeepSeek/OpenAI |

## 四、两个项目的核心机制

### AI-Local（种草卡增长）

**业务闭环**：建商家 → 建种草卡(二维码) → 顾客扫码 → H5落地页(商家信息+AI好评复制+跳转) → 事件上报 → 数据看板(趋势)。

**关键点**：
- H5 落地页是 `h5/index.html` + `h5/assets/app.js`（纯静态，无框架）
- AI 好评接口：`GET /api/seed-card/public/{slug}/review`（公开，无需登录）
- 商家资料公开接口：`GET /api/seed-card/public/{slug}`
- 事件类型：scan/click/share/comment

### WeChat-POI（团购小程序）

**业务闭环**：平台建商户/门店/套餐 → 顾客在小程序下单 → Mock支付 → 到店核销(幂等防重) → 数据看板。

**关键点**：
- **单商户小程序模式**：一套模板 + 每个商家一个 `merchant_code`，小程序启动按 code 加载该商家数据
- 公开接口：`GET /api/v1/public/config?code=xxx`（小程序端用，返回品牌+门店+套餐）
- 支付/地图/通知都是 Provider 抽象（mock/real 切换），默认 mock
- 核销幂等：重复核销返回 4001

## 五、启动方式（本地开发）

### 环境要求
- Python ≥ 3.11
- Node.js ≥ 18

### AI-Local
```bash
cd AI-Local-Growth-SaaS/backend
pip install -r requirements.txt
python seed_admin.py          # 建表+种子账号（admin/admin123, merchant/merchant123）
python main.py                # 或 uvicorn main:app --port 8000
```

### WeChat-POI 后端
```bash
cd WeChat-POI-Groupbuy-SaaS/backend
pip install -r requirements.txt   # Windows 开发用这个
python -m scripts.seed           # 建表+种子（admin/merchant/manager/verifier）
uvicorn app.main:app --port 8001
```

### 前端（两个项目都是 React+Vite）
```bash
cd AI-Local-Growth-SaaS/frontend      # 或 WeChat-POI-Groupbuy-SaaS/web-admin
npm install
npm run dev                           # 开发模式
npm run build                         # 生产构建（WeChat 用 VITE_API_BASE=/api/v1）
```

## 六、生产部署（Docker）

两个项目都有 `docker/` 目录，用 Docker Compose 部署：

```bash
cd AI-Local-Growth-SaaS
docker compose -p ai-local -f docker/docker-compose.yml up --build -d

cd WeChat-POI-Groupbuy-SaaS
docker compose -p wechat -f docker/docker-compose.yml up --build -d
```

**⚠️ 关键注意**：
1. 两个项目必须用不同 `-p` 项目名（`ai-local` / `wechat`），否则容器名冲突
2. Dockerfile 里已配阿里云 apt/pip 源（国内加速，勿删）
3. 生产 `.env` 在项目根目录（不入 git，需手动创建）

## 七、统一约定（修改代码时必须遵守）

1. **统一响应结构**：`{ "code": 0, "message": "ok", "data": {} }`，code=0 成功
2. **金额单位**：一律「分」（整数），前端展示时 ÷100
3. **软删除**：禁止物理 DELETE，用 status 字段或 deleted_at
4. **多租户隔离**：WeChat 项目查询必须走 `tenant_filter()`，禁止手写 if 判断租户
5. **禁止硬编码**：配置走 config.py + 环境变量（.env 不入 git）
6. **密钥不入库**：`.env`、`.db`、`node_modules`、`dist` 都在 .gitignore 里
7. **测试**：改完代码跑 `pytest`（AI-Local 27 个、WeChat 23 个用例）

## 十、给其他智能体的修改建议
