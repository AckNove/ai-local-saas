# 小程序模板 + 商家自动生成 使用说明

> 目标：接一个商家，你只需在后台填资料 + 改一个配置，就能生成该商家专属的小程序。
> 核心机制：**一套小程序模板 + 每个商家一个 merchant_code**，小程序启动时按 code 自动加载该商家的品牌和套餐。

---

## 一、核心概念

| 概念 | 是什么 |
|---|---|
| **小程序模板** | `miniprogram/` 这一套代码，所有商家共用 |
| **merchant_code** | 每个商家的唯一标识（你在后台填，如 `shop_abc`） |
| **自动生成** | 小程序 config.js 里填了 code，启动就自动加载该商家的店名、logo、套餐 |

---

## 二、接一个新商家的完整流程

### 第 1 步：后台建商家 + 设 merchant_code

1. 登录后台 → 「商户管理」→「新增商户」
2. 填：商户名称、Logo、电话、**商家标识**（如 `shop_zhangsan`）
3. 保存

### 第 2 步：后台建门店 + 上架套餐

1. 「门店管理」→ 新增门店（填地址、POI）
2. 「套餐管理」→ 新建套餐（填名称、价格、图片、适用门店）→ 点「上架」

### 第 3 步：生成商家小程序

1. 复制 `miniprogram/` 整个文件夹，改个名（如 `miniprogram-zhangsan`）
2. 打开 `config.js`，改 **两个值**：
   ```js
   MERCHANT_CODE: 'shop_zhangsan',   // 填后台设置的商家标识
   APP_ID: 'wx商家自己的AppID',       // 商家注册认证后拿到的
   MOCK: false,                       // 接真实后端
   API_BASE: 'http://你的服务器IP:8000/api/v1',
   ```
3. 用「微信开发者工具」打开这个文件夹 → 填 AppID → 上传 → 提交审核

### 第 4 步：视频号 POI 挂载

小程序审核通过后，在视频号发内容 → 挂 POI → 关联这个商家小程序 → 顾客就能在视频号里下单。

---

## 三、商家资料驱动了什么

后台填的商家资料，会自动体现在小程序里：

| 后台填的 | 小程序里显示 |
|---|---|
| 商户名称 | 首页顶部品牌名、导航栏标题 |
| Logo | 品牌 Logo（可扩展） |
| 联系电话 | 联系商家 |
| 门店地址/POI | 门店信息 |
| 套餐（已上架的） | 首页套餐列表 |

**所以：你在后台改套餐、改价格、改门店，商家的小程序自动跟着变，不需要重新上传小程序代码。**

---

## 四、自动生成"能做到/做不到"的边界

| 项 | 能否自动 |
|---|---|
| 商家资料 → 小程序品牌外观 | ✅ 全自动 |
| 套餐/门店数据 → 小程序内容 | ✅ 全自动 |
| 生成商家专属配置 | ✅ 全自动 |
| **注册小程序、拿 AppID、上传审核** | ❌ 微信规定必须人工（每家约10分钟 + 审核1-3天） |

> "自动生成"帮你省的是**写代码、改样式、配数据**这些活；"注册审核"这一步是微信的硬规定，绕不开，但也就几分钟的事。

---

## 五、技术要点（供以后维护）

- 后端新增公开接口 `GET /api/v1/public/config?code=xxx`（无需登录，小程序端用）
- 后端 `Merchant` 模型新增 `merchant_code` 字段（唯一）
- 小程序 `config.js` 加 `MERCHANT_CODE`，`app.js` 启动时拉配置存 globalData
- 首页 `index.js` 改为按 code 拉本商家套餐（不再拉全部）
