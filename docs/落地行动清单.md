- **日期**：2026-08-15

## 一、最重要的一句判断

> 你现在两个项目是**能演示的原型**，不是**能收钱的成品**。卡点不在代码，在**资质 + 服务器**。顺序错了会白花钱。

---

## 二、主体资质（一切的前提）

**结论：办"个体工商户"就够了，不用注册公司，几乎免费。**

| 事项 | 说明 |
|---|---|
| 办理主体 | 个体工商户（非"个人"，个人不能开通微信支付） |
| 去哪办 | 当地市场监管局线上平台（如"企业开办一网通"）或政务窗口 |
| 成本 | 约 0 元（代办也才几百） |
| 周期 | 几天到一两周拿执照 |
| 用途 | 小程序认证、微信支付商户号，都认这个执照 |

> 拿到个体户执照后，才能往下办小程序和支付。这是唯一需要你亲自跑腿的事，其余都是代码/配置。

---

## 三、真实收付款链路：从今天开始做什么（按顺序）

| 步骤 | 做什么 | 去哪办 | 成本 | 状态 |
|---|---|---|---|---|
| 1 | 办个体工商户执照 | 市场监管局线上 | ~0 元 | 你来做 |
| 2 | 注册微信小程序，个体户主体认证 | 微信公众平台 | 300 元/年 | 执照拿到后 |
| 3 | 申请微信支付商户号（mchid + API v3 密钥） | 微信支付商户平台 | 免费 | 小程序认证后 |
| 4 | 填 `backend/.env`：APPID/SECRET/MCHID/API密钥，`WECHAT_PAY_PROVIDER=real` | 你自己改配置 | 免费 | 凭证到手后 |
| 5 | 补支付回调验签（防伪造回调） | 代码 | 0 | 我帮你写 |
| 6 | （可选）开通微信支付**分账**权限 → 自动抽佣 | 微信支付商户平台 | 需资质 | 后期 |

**关键提醒**：不开分账时，顾客的钱**直接进商家微信账户**，你截不住。只能"线下对账"——看后台 GMV，月底人工找商家收佣金。对商户少的阶段，这是最省事、最现实的做法。

## 四、视频号 POI 团购的正确姿势

- **一个平台小程序 + 多商家入驻**（就是你项目 `miniprogram/` 这套），不是一家一个小程序。
- 商家自己已有小程序：建议直接用你的平台小程序，别碰他的小程序（省事 + 你才能抽佣）。
- 流程：平台小程序认证 → 商家入驻 → 商家上团购 → 消费者在小程序下单（微信支付）→ 到店扫码核销 → 平台看 GMV 抽佣。

## 五、种草卡新模式（已实现，合规版）

**你原设想**："顾客扫码 → AI 自动粘贴好评 → 顾客一键点赞+评价"——**做不到且违规**（微信/小红书禁止代用户点赞评论，会封号）。

**合规替代（已做完）**：
```
顾客扫码 → 打开落地页
→ AI 已生成好"好评文案"并展示
→ 顾客点「复制好评」（一键复制到剪贴板）
→ 点「前往视频号/小红书」跳转
→ 顾客在评论区「粘贴」发送
```

**后台怎么用**：
1. 登录 http://127.0.0.1:8000（admin/admin123）
2. 「商家管理」→ 新增商家（填门店、视频号账号）
3. 「种草卡管理」→ 创建种草卡（跳转目标填视频号链接，类型选二维码）
4. 详情页下载二维码 → 打印贴到店里
5. 顾客扫码 → 落地页有 AI 好评+复制按钮 → 后台「数据概览」看扫码/评论数据

> 现状边界：没有真 NFC 碰一碰（只存了字段），跳转目标要你自己填视频号/小红书链接。跟商家沟通时叫"扫码种草卡/到店互动码"，别说 NFC。

## 七、地推建议（成本有限版）

1. **先用"扫码种草卡 + AI 内容"去谈商家**（现在就能交付、能收钱），别拿"小程序团购交易"当主打——那部分你还没资质。
2. 话术：**"我帮你把到店客户变成视频号传播客户"**，先免费送一份诊断报告，再现场演示"1 分钟生成好评 + 种草卡"。
3. 报价参考（你 PRD 里的）：2980 元/半年，含系统使用 + 种草卡 + AI 内容 + 数据。
4. 等谈成 3-5 个付费商家、验证需求后，再用收入去办小程序 + 支付，别自己先垫钱。

## 八、两个项目的关系

- **AI-Local（增长服务）**：帮商家做种草卡 + AI 内容 → "引流"，现在就能用、能收服务费。
- **WeChat-POI（团购平台）**：帮商家上团购 + 收钱 + 核销 → "变现"，需要小程序+支付资质后才能商用。
- 路线：先用 AI-Local 攒商家 → 办资质 → 商家迁到 WeChat-POI 收佣金。**一前一后，不是并行。**
