## 阶段 1：连接 + 装 Docker（约 5 分钟）

```bash
ssh root@你的公网IP
# 首次连输入 yes，再输密码

# 装 Docker
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version   # 验证
```

---

## 阶段 2：上传代码

两个项目各打一个 zip，或 git clone。推荐 git（有版本记录）。

```bash
# 服务器上建目录
mkdir -p ~/apps && cd ~/apps

# 上传后解压（或 git clone）
```

## 阶段 3：配置生产环境变量（重点）

### AI-Local 项目 `.env`（在项目根目录）

```
POSTGRES_USER=saas
POSTGRES_PASSWORD=随机强密码
POSTGRES_DB=growth
JWT_SECRET=随机32位以上字符串
PUBLIC_BASE_URL=http://你的IP:8000
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的key（可选，缺省走mock）
CORS_ORIGINS=http://你的IP:8000
```

### WeChat 项目 `.env`（在项目根目录）

```
POSTGRES_USER=wechat
POSTGRES_PASSWORD=随机强密码
POSTGRES_DB=groupbuy
JWT_SECRET=随机32位以上字符串
```

## 阶段 4：启动（每个项目一条命令）

```bash
cd ~/apps/AI-Local-Growth-SaaS
docker compose -f docker/docker-compose.yml up --build -d

cd ~/apps/WeChat-POI-Groupbuy-SaaS
docker compose -f docker/docker-compose.yml up --build -d
```

---

## 阶段 5：放行防火墙（云控制台操作，最容易漏！）

- 腾讯云：控制台 → 轻量服务器 → **防火墙** → 添加规则
- 阿里云：控制台 → 安全组 → 添加规则

放行 TCP 端口：**8000、8001**（如用域名还要放 80/443）

---

## 阶段 6：验证

浏览器访问：
- http://你的IP:8000/api/health → `{"code":0,...}`
- http://你的IP:8001/api/health → `{"code":0,...}`

服务器命令行验证：
```bash
curl http://127.0.0.1:8000/api/health
curl http://127.0.0.1:8001/api/health
```

## 常见坑（提前知道，少走弯路）

| 坑 | 原因 | 解决 |
|---|---|---|
| 浏览器打不开 | 防火墙没放行端口 | 阶段 5 放行 |
| 构建失败 | 服务器内存不够 | 换 2核4G 或先只部署一个 |
| 数据库报错 | .env 的 POSTGRES_PASSWORD 没改 | 改随机强密码 |
| 商家访问慢 | 服务器地域远 | 买的时候选离自己近的地域 |
| 密码发出去怕泄露 | — | 部署完改密码 |
