## 阶段 0：买服务器 + 办执照（并行，现在就开始）

### 步骤 0-1：买服务器（约 5 分钟，约 38-100 元）

**做什么**：买一台云服务器。
**去哪做**：腾讯云或阿里云官网。

具体操作（照着点）：
1. 手机号注册（必须是**新用户**才有 38 元价）
2. 搜「轻量应用服务器」→ 选「新用户专享」
3. 选配置：
   - 地域：广州或上海
   - 镜像：**Ubuntu 22.04**
   - 套餐：**2核2G**（最低配）
   - 时长：1 年
4. 付款
5. 记下三个东西：**公网IP、用户名 root、密码**

**做完后**：把「IP + 密码」发给我，我帮你部署。

### 步骤 0-2：办个体工商户执照（约 0 元，几天到两周）

**做什么**：办一个个体户营业执照。
**去哪做**：当地市场监管局线上平台（搜"你所在城市 + 个体工商户网上登记"）。

具体操作：
1. 准备：身份证、经营地址（可以写你家的地址或挂靠地址）
2. 在线提交申请（经营范围可写"信息技术服务、软件开发、广告设计"等）
3. 等审批（几天到两周）
4. 拿执照

**做完后**：执照到手，后面注册小程序、办支付都用它。

> 这两个可以同时做，互不依赖。

## 阶段 1：我帮你部署系统上线（你只需提供信息）

**做什么**：把系统部署到你的服务器上，让商家能访问。
**谁做**：**我全包**，你只需提供服务器 IP + 密码。

我会做：
1. 连服务器装 Docker
2. 上传代码
3. 配置环境变量
4. 启动两个项目
5. 放行防火墙端口
6. 验证 `http://你的IP:8000` 能打开

**做完后**：你有一个能发给商家看的网址。

## 阶段 2：注册小程序 + 真机验证（执照到手后）

### 步骤 2-1：注册小程序，拿 AppID（约 1-3 天，300元/年）

**做什么**：注册一个小程序（先用你自己的执照注册一个，作为测试）。
**去哪做**：[微信公众平台](https://mp.weixin.qq.com) → 注册 → 选「小程序」。

具体操作：
1. 用你的个体户执照信息注册
2. 主体类型选「个体工商户」（不是个人）
3. 完成微信认证（300 元/年）
4. 拿到 **AppID**（形如 `wx1234567890`）

**做完后**：把 AppID 告诉我，我帮你填进小程序配置。

### 步骤 2-2：真机验证小程序（约 30 分钟）

**做什么**：用微信开发者工具把小程序跑起来，手机扫码测试。
**去哪做**：下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

具体操作：
1. 安装开发者工具
2. 导入 `miniprogram/` 文件夹 → 填 AppID
3. 点「预览」→ 微信扫码 → 手机上看效果

**做完后**：你在手机上能看到小程序真实跑起来（这就是将来商家的顾客看到的）。

## 阶段 3：地推谈商家（收到第一笔开发费）

**做什么**：用你做好的系统 + 话术，去谈商家。
**谁做**：你（我用话术帮你）。

具体操作：
1. 筛选目标商家（优先：地图上能搜到、有视频号、高客单价的美容/健身/餐饮）
2. 用 4 步话术谈（破冰→免费诊断→现场演示→报价）
3. 报价：**开发费 2500-3000 + 月维护 500-600**
4. 目标：**先谈成 1 家，收到第一笔开发费**

**话术和诊断报告模板**：见 `docs/地推话术与诊断报告模板.md`。

---

## 阶段 4：给商家交付（用你的模板，半天一家）

**做什么**：商家交钱后，帮他落地小程序 + 团购 + POI。
**谁做**：你操作（系统已做好，你只需填资料）。

具体操作（照 `docs/小程序模板与商家自动生成说明.md`）：

1. **后台建商家**：填商家名称、logo、电话、**商家标识**（如 `shop_zhangsan`）
2. **建门店 + 上架套餐**：填地址、POI、套餐名称价格图片
3. **生成商家小程序**：
   - 复制 `miniprogram/` 文件夹
   - 改 `config.js` 里的 `MERCHANT_CODE`（商家标识）和 `APP_ID`（商家的 AppID）
4. **上传审核**：开发者工具上传 → 提交审核（1-3 天）
5. **视频号挂载**：审核通过后，帮商家在视频号发内容挂 POI 关联小程序

> 关键：商家的小程序认证（300元/年）由商家自己出（方案A），用**商家的执照**注册。

## 阶段 5：每月维护（收月费 500-600）

**做什么**：每月给商家持续服务。
**谁做**：你 + 系统（AI-Local 自动化）。

每月做的事：
1. 种草卡数据维护（看扫码/点击数据，出报告）
2. 小程序维护（改套餐、改价格、上新品）
3. AI 内容（用 AI-Local 生成视频脚本、评论）
4. 每月一条宣传视频（商家拍素材，你剪辑 + AI 写脚本）

**收费**：每月 500-600 元/家。有 10 家商家，月收入就是 5000-6000 元。
