# 阿里云安全组放行端口操作步骤（唯一需要你手动做的一步）

> 你的服务已经部署到服务器，但**公网访问被阿里云"安全组"挡住了**。
> 安全组是阿里云控制台层面的防火墙，我无法通过 SSH 帮你改，需要你在网页上点几下。

---

## 操作步骤（约 2 分钟）

### 第 1 步：登录阿里云控制台

浏览器打开 [阿里云控制台](https://home.console.aliyun.com)，用你买服务器的账号登录。

### 第 2 步：找到你的服务器

- 顶部搜索框输入「**轻量应用服务器**」，点进去
- 找到你那台服务器（IP 是 8.134.36.218）

### 第 3 步：进入「防火墙」页面

在服务器详情页，找到左侧菜单或标签里的「**防火墙**」（有的版本叫「安全组」）。

### 第 4 步：添加两条规则

点「**添加规则**」，分别添加下面两条：

**规则 1：**
- 协议：**TCP**
- 端口：**8000**
- 授权对象/来源：**0.0.0.0/0**（允许所有人访问）

**规则 2：**
- 协议：**TCP**
- 端口：**8001**
- 授权对象/来源：**0.0.0.0/0**

> 如果界面是让你填「端口范围」，就填 8000-8001（一次放行两个）。

### 第 5 步：保存

点确认保存，等几秒钟生效。

---

## 放行后验证

放行后，在浏览器打开这两个地址：

```
http://8.134.36.218:8000   ← AI-Local 管理后台（admin / admin123）
http://8.134.36.218:8001   ← WeChat 管理后台（admin / admin123）
```

能打开就成功了。
