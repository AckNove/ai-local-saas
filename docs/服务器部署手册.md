# 服务器部署手册（低成本版）

> 适用对象：非技术背景的经营者。目标是"照着做，把两个服务跑到公网，商家随时能访问"。
> 前提：你有一台能联网的 Windows 电脑（当"遥控器"用），不需要懂 Linux。

---

## 0. 先搞清楚一件事

**服务器 = 你租的一台远程电脑（Linux 系统），跟你的 Windows 电脑无关。**
你的 Windows 电脑只用来"远程连上去敲命令"。所有命令我都写好了，复制粘贴即可。

---

## 1. 买服务器（第一年约 100 元）

### 选哪家、选什么

| 项 | 推荐 |
|---|---|
| 厂商 | 腾讯云 或 阿里云（都行，选便宜的） |
| 产品 | **轻量应用服务器**（不是"云服务器 CVM"，轻量更简单便宜） |
| 地域 | 离你近的，如广州/上海 |
| 镜像 | **Ubuntu 22.04** 或 **Ubuntu 24.04**（选 Linux，不要选 Windows） |
| 配置 | **2核 2G 内存**（最低配，够用） |

> 新用户首年通常 50-100 元，认准"新用户专享"价格。
> 参考：[2025 便宜云服务器选购指南](https://cloud.tencent.com/developer/article/2581833)

### 买完拿到什么

1. 服务器的 **公网 IP**（一串数字，如 `43.xxx.xxx.xxx`）
2. 登录用的 **用户名**（Ubuntu 默认 `root` 或你设的用户名）
3. 登录用的 **密码**（或密钥文件）

---

## 2. 从你的 Windows 电脑连上服务器

### 方法：用 Windows 自带的"终端"或 PowerShell

按 `Win + R`，输入 `powershell` 回车，然后在里面输入：

```powershell
ssh root@你的公网IP
```

第一次会问 `yes/no`，输入 `yes` 回车；再输入密码（**输密码时屏幕不显示，正常现象**），回车。

连上后，你看到的命令行会变成 `root@xxx:~#`，说明已经"进到服务器里了"。

> 如果 `ssh` 提示找不到命令，说明你的 Windows 版本太老，去微软商店装一个"Windows 终端"或用 [FinalShell](https://www.hostbuf.com)（中文图形界面，对新手更友好）。

---

## 3. 在服务器上装 Docker（一次性，约 5 分钟）

连上服务器后，**逐条复制粘贴**下面命令（每粘贴一条按回车，等它跑完再下一条）：

```bash
# 更新软件源
apt-get update

# 装 Docker（一条命令，自动装好）
curl -fsSL https://get.docker.com | sh

# 启动 Docker 并设置开机自启
systemctl enable --now docker

# 验证装好了（能显示版本号就成功）
docker --version
```

---

## 4. 把你的代码传到服务器

你有两个项目要传：`AI-Local-Growth-SaaS` 和 `WeChat-POI-Groupbuy-SaaS`。

### 方法 A：用 git（如果你有 GitHub/Gitee 仓库）

```bash
# 在服务器上克隆（把地址换成你的仓库地址）
git clone 你的仓库地址
```

### 方法 B：直接打包上传（没有 git 的话）

1. 在你的 Windows 电脑上，把两个项目文件夹分别压缩成 `.zip`
2. 用 [FinalShell](https://www.hostbuf.com) 或 WinSCP 的**文件拖拽**功能，把 zip 拖到服务器
3. 在服务器上解压：

```bash
apt-get install -y unzip
unzip AI-Local-Growth-SaaS.zip
unzip WeChat-POI-Groupbuy-SaaS.zip
```

## 5. 配置环境变量（关键，别跳过）

每个项目都要准备一个 `.env` 文件。在服务器上，进入项目目录后创建：

```bash
# 进入 AI-Local 项目根目录
cd ~/AI-Local-Growth-SaaS
# 创建环境变量文件
cat > .env << 'EOF'
POSTGRES_USER=saas
POSTGRES_PASSWORD=改成你自己的强密码
POSTGRES_DB=growth
JWT_SECRET=改成一串很长的随机字符至少32位
PUBLIC_BASE_URL=http://你的公网IP:8000
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的DeepSeek密钥
CORS_ORIGINS=http://你的公网IP:8000
EOF
```

```bash
# 进入 WeChat 项目根目录
cd ~/WeChat-POI-Groupbuy-SaaS
cat > .env << 'EOF'
POSTGRES_USER=wechat
POSTGRES_PASSWORD=改成你自己的强密码
POSTGRES_DB=groupbuy
JWT_SECRET=改成一串很长的随机字符至少32位
EOF
```

> ⚠️ 重点：
> - `JWT_SECRET` 必须改成随机长字符串，否则不安全。
> - `DEEPSEEK_API_KEY` 填你自己的（AI-Local 用，没有就留空走 mock）。
> - 现在不填微信支付、地图这些，等资质办好再加。

## 6. 启动两个服务

```bash
# 启动 AI-Local（在 AI-Local-Growth-SaaS 目录）
cd ~/AI-Local-Growth-SaaS
docker compose -f docker/docker-compose.yml up --build -d

# 启动 WeChat（在 WeChat-POI-Groupbuy-SaaS 目录）
cd ~/WeChat-POI-Groupbuy-SaaS
docker compose -f docker/docker-compose.yml up --build -d
```

第一次会下载依赖、构建镜像，需要等几分钟。完成后验证：

```bash
# 浏览器访问这两个地址（把 IP 换成你的）
# http://你的公网IP:8000/api/health   → 应该返回 {"code":0,...}
# http://你的公网IP:8001/api/health   → 应该返回 {"code":0,...}
```

在服务器上用命令行验证：

```bash
curl http://127.0.0.1:8000/api/health
curl http://127.0.0.1:8001/api/health
```

## 7. 放行防火墙端口（关键！否则外面访问不到）

云服务器有个"安全组"（类似防火墙），默认只开 22 端口，必须手动放行 8000、8001。

- **腾讯云**：控制台 → 轻量服务器 → 防火墙 → 添加规则，放行 TCP 端口 `8000` 和 `8001`
- **阿里云**：控制台 → 安全组 → 添加规则，放行 TCP `8000` 和 `8001`

放行后，外面才能用 `http://公网IP:8000` 访问。

## 8. 让服务"永不掉线"（解决你之前那个老问题）

Docker 配置里已经写了 `restart: unless-stopped`，意思是：

- **服务器重启后，服务会自动拉起**
- **服务崩溃后，会自动重启**

这就是为什么用 Docker 部署——彻底解决你之前"关掉会话服务就死"的问题。

常用管理命令（以后维护用）：

```bash
# 查看运行状态
docker ps

# 看日志（排查问题）
docker compose -f docker/docker-compose.yml logs -f app

# 重启服务
docker compose -f docker/docker-compose.yml restart

# 更新代码后重新构建
docker compose -f docker/docker-compose.yml up --build -d
```

## 9. （可选但强烈建议）绑定域名 + 备案

现在你能用 `http://公网IP:8000` 访问，但：
- IP 数字不好记、不专业
- **国内服务器不备案，80/443 端口会被封**（用域名+备案才正规）

步骤：
1. 买域名（阿里云/腾讯云，约 50 元/年，如 `xxx.com`）
2. 域名解析到你的公网 IP（A 记录）
3. 在云厂商提交**ICP 备案**（免费，约 1-2 周，按提示填资料即可）
4. 备案通过后，配置用域名访问

> 备案是"必须做但有点麻烦"的一步。**如果暂时只想给商家看演示，可以先用 IP 访问，备案晚点办。**

## 11. 常见问题

**Q：我完全不懂 Linux，能搞定吗？**
A：能。本手册所有命令都是"复制粘贴回车"，你不需要理解每句是什么意思。

**Q：部署失败卡住了怎么办？**
A：把报错信息发给我，我帮你判断。最常见是：防火墙没放行、.env 没配好、命令少复制了一行。

**Q：先部署一个项目行不行？**
A：行。建议**先只部署 AI-Local**（你当前地推要用它），跑通后再部署 WeChat。

**Q：两个项目能都放一台服务器吗？**
A：能。它们用不同端口（8000 和 8001），同一台 2核2G 服务器足够。
